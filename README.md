# مُنظم — منظم حياة مدرس
تصميم حازم حسن

تطبيق Flutter يشتغل كـ PWA على الآيفون والأندرويد، وله نسخة Android أصلية بإشعارات محلية، وإعداد تطبيق iOS أصلي لفتح أرقام الدخل ببصمة الوجه. البيانات كلها محفوظة داخل الجهاز (shared_preferences → localStorage في الـ PWA).

## التشغيل والبناء

```bash
flutter pub get
flutter run -d chrome

flutter build web --release
flutter build apk --release --split-per-abi --split-debug-info=build/symbols
```

ينشئ الأمر ملفات أصغر لكل معمارية داخل `build/app/outputs/flutter-apk/`؛ لمعظم الهواتف الحديثة اختر `app-arm64-v8a-release.apk`. استخدم `app-armeabi-v7a-release.apk` للأجهزة القديمة 32-bit، أو `app-x86_64-release.apk` للمحاكيات/الأجهزة x86-64. إعداد Android يطلب إذن الإشعارات، ويعيد جدولة تذكيرات الحصص بعد إعادة تشغيل الجهاز. APKs الحالية موقّعة بمفتاح debug للتجربة والتثبيت المباشر؛ النشر على المتجر يتطلب إعداد مفتاح توقيع إصدار خاص.

ارفع محتوى `build/web` على أي استضافة HTTPS (Firebase Hosting / Netlify / GitHub Pages). ملفات Flutter والأيقونات تُخزّن محليًا بعد أول فتح ناجح، وبعدها يمكن فتح التطبيق دون إنترنت. يلزم HTTPS، وافتح التطبيق مرة وهو متصل لإكمال التخزين المؤقت.
على الآيفون: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية». على الأندرويد: Chrome ← «تثبيت التطبيق».

## النشر على GitHub Pages
- ارفع ملفات المشروع إلى مستودع GitHub على الفرع `main`. ملف `.github/workflows/deploy-pages.yml` يبني نسخة الويب وينشرها تلقائيًا بعد كل push، مع ضبط مسار المشروع تلقائيًا.
- من المستودع افتح **Settings → Pages** واختر **GitHub Actions** كمصدر النشر. بعد نجاح سير العمل، افتح الرابط الظاهر في **Actions → Deploy Flutter web app to GitHub Pages**.
- افتح الرابط أول مرة من Safari على الآيفون مع اتصال الإنترنت، ثم اختر **مشاركة → إضافة إلى الشاشة الرئيسية**. شغّل التطبيق مرة وهو متصل حتى يكتمل التخزين؛ بعد ذلك تعمل الواجهة والأيقونات دون إنترنت. بيانات التطبيق محفوظة على الجهاز نفسه ولا تُزامَن مع GitHub أو أجهزة أخرى.

## تشغيل تطبيق iOS وFace ID
- يتطلب بناء تطبيق iOS جهاز Mac عليه Xcode؛ شغّل `flutter build ios --no-codesign`، وبعدها افتح `ios/Runner.xcworkspace` في Xcode واضبط توقيع التطبيق قبل تثبيته على الآيفون.
- في تطبيق iOS الأصلي، تُقفل أرقام الدخل في تبويب المدرسة ويُطلب Face ID لعرضها، وتُقفل مجددًا عند مغادرة التطبيق. يجب إعداد Face ID على الجهاز.
- نسخة الويب/PWA تظل دون قفل بيومتري؛ Face ID متاح في تطبيق iOS الأصلي فقط.

## ملاحظات البناء
- لتنفيذ بناء Android، ثبّت Android SDK واقبل تراخيصه باستخدام `flutter doctor --android-licenses`.
- إذا كان المطلوب توزيع APK رسميًا، أعدّ إعداد توقيع إصدار خاص بدل توقيع debug الافتراضي.

## طريقة الحساب
- **المدرسة**: اليومية = المرتب ÷ عدد أيام عملك في نفس الشهر. اليوم اللي بتعلّم عليه «ماروحتش» بيتخصم.
- **دخل اليوم في تبويب المدرسة**: اليومية المدرسية عند تسجيل الحضور + أسعار حصص البرايفت المنفذة والمؤكدة في سجل اليوم. إضافة حصص البرايفت هنا لا تغيّر إجماليات الملخص أو الشهر.
- **السنتر**: التحصيل الشهري يتابع الطلاب اللي اتعلّم عليهم «دفع». في الملخص، قيمة الحصة المنفذة = سعر الطالب الشهري ÷ ٨ × عدد طلاب المرحلة، وتُضاف بتاريخ تسجيل الحصة. المصاريف الشهرية بتتوزع على الأيام.
- **البرايفت**: كل طالب عنده ٨ خانات. لما تسجّل حصته في آخر اليوم تُضاف قيمة الحصة للملخص بتاريخها؛ زر «استلمت» يتابع التحصيل الفعلي منفصلًا.
- **تسجيل الحصص**: بتظهر مجموعات السنتر وطلاب البرايفت المواعيد المحددة لهم في اليوم المختار فقط، مع إبقاء الحصص المسجلة بالفعل قابلة للتعديل.
- **مواعيد الحصص**: لكل يوم تختاره ميعاد مستقل للسنتر وللبرايفت، مع استمرار قراءة المواعيد القديمة ذات الوقت الموحد.
- **الحصص السابقة**: عند إضافة أو تعديل مرحلة سنتر أو طالب برايفت، يمكن اختيار الأيام السابقة من التقويم لتظهر الحصص في سجلات الأيام وتُحسب ضمن حصص الطالب ومستحقاته.
- **الملخص**: اليوم والأسبوع والترم تعرض الدخل المكتسب من الحضور والحصص المؤكدة بتاريخ تنفيذها. الشهر يعرض المقبوض فقط: تسجيل استلام مرتب المدرسة من تبويب المدرسة، ومدفوعات السنتر والبرايفت من أماكنها. قيمة حصة السنتر = سعر الطالب الشهري ÷ ٨ × عدد طلاب المرحلة، وحصة البرايفت بسعر الحصة المسجل. عند بداية شهر جديد يظهر تنبيه بالفروق بين قيمة الشغل والمقبوض للشهر السابق، لكل مصدر على حدة. بيانات الأيام السابقة تظل محفوظة والفترات الحالية لا تشمل المستقبل.
- **الترم**: الأول من 1 سبتمبر لـ 31 يناير، والتاني من 1 فبراير لـ 30 يونيو.
- **صافي الدخل المكتسب** = دخل المدرسة + دخل حصص السنتر − مصاريف السنتر + قيمة حصص البرايفت. **صافي المقبوض الشهري** = المرتب المستلم + تحصيل السنتر + تحصيل البرايفت − مصاريف السنتر.

## المنبه (مهم)
- تطبيق Android وiOS يطلب إذن الإشعارات ويجدول إشعارًا متكررًا قبل كل موعد حصة بـ١٥ دقيقة. على Android، يُستخدم المنبه الدقيق عند السماح به، مع قناة إشعارات ذات صوت وأهمية عالية، وتُستعاد المواعيد بعد إعادة تشغيل الجهاز. الإشعار يوضح نوع الحصة واسم الطالب المسجل، وتظهر الحصة القادمة واسم الطالب أيضًا على الشاشة الرئيسية. يتم تحديث الإشعارات عند تعديل المواعيد.
- عند رفض الأذونات، فعّل إشعارات مُنظم من إعدادات الجهاز. قد يتأخر التنبيه على Android إذا لم يُسمح بالمنبه الدقيق، كما قد تمنع إعدادات عدم الإزعاج/الصامت أو تقييدات البطارية الصوت أو التسليم. إيقاف التطبيق إجباريًا من إعدادات النظام قد يوقف التنبيهات حتى فتحه مرة أخرى. نسخة الويب/PWA لا تضمن إشعارات عند إغلاق المتصفح.
- يظل منبه تسجيل حصص اليوم منفصلًا: بعد ميعاده (الافتراضي 9 م، ويمكن تغييره من الإعدادات) يفتح شاشة التسجيل تلقائيًا عند استخدام التطبيق إن لم يُسجّل اليوم.
